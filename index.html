04: LOGIC

Teach your code
how to decide.

Conditional statements allow PHP to execute different code depending on whether a condition is true or false.

QUESTION Is the age 18 or higher?
$age >= 18?
TRUE
You can vote. echo "Yes";
FALSE
Not yet. echo "No"; 
if ($age >= 18) {
    echo "You can vote.";
} else {
    echo "Not yet.";
}

06: FUNCTIONS

Build reusable
pieces of logic.

Functions group instructions into a reusable block. You can call the function whenever you need it.

FUNCTION greet()
+
INPUT $name
+
OUTPUT Hello 
function greet($name) {
    return "Hello " . $name;
}

echo greet("Joana");
